# 한국어 문법 201: <span style="color:#3b7dd8">V/A-(으)며</span>

'나나는 춤을 잘 <span style="color:#f24f9d">추며</span> 노래도 잘해요.'

## ❣ 1. 예문

- 미소: 나나는 춤을 잘 <span style="color:#f24f9d">추며</span> 노래도 잘해요.
- 미소: 이 호텔은 시설이 <span style="color:#f24f9d">좋으며</span> 서비스도 훌륭합니다.

## ❣ 2. 용법

- 두 가지 이상의 동작이나 상태, 사실을 나열할 때 사용
- 동사/형용사 어간 뒤에, 또는 명사-이다 뒤에 사용
- 대부분 '-고'로 바꿔서 사용할 수 있음
- '-(으)며'는 주로 글(문어)에서 사용, '-고'는 말·글 모두 사용
- 예문

✎ 미소: 나나는 춤을 잘 <span style="color:#f24f9d">추며</span> 노래도 잘해요. (추다 + 며 → 동사)

✎ 미소: 이 호텔은 시설이 <span style="color:#f24f9d">좋으며</span> 서비스도 훌륭합니다. (좋다 + 으며 → 형용사)

✎ 미소: 나나는 모든 일에 <span style="color:#f24f9d">적극적이며</span> 진취적인 태도를 보입니다. (적극적이다 + 며 → 명사-이다)

\* 나열할 때는 앞뒤 문장을 바꿔도 같은 뜻

- 나나는 춤을 잘 추며 노래도 잘해요. = 나나는 노래를 잘하며 춤도 잘 춰요.

## ❣ 3. 결합정보

- 동사/형용사, 명사-이다와 결합합니다.

| <span style="color:#f24f9d">받침 O</span> | <span style="color:#f24f9d">받침 X</span> · 명사-이다 | <span style="color:#f24f9d">받침 ㄹ</span> (ㄹ 유지) |
|:---:|:---:|:---:|
| -으며 | -며 | -며 |
| 먹다 + 으며<br>→ <span style="color:#f24f9d">먹으며</span><br>맑다 + 으며<br>→ <span style="color:#f24f9d">맑으며</span> | 가다 + 며<br>→ <span style="color:#f24f9d">가며</span><br>적극적이다 + 며<br>→ <span style="color:#f24f9d">적극적이며</span> | 만들다 + 며<br>→ <span style="color:#f24f9d">만들며</span> |

## ❣ 4. 연습

1\. 이 옷은 (편하다) 디자인도 예뻐요.

→ 이 옷은 <span style="color:#f24f9d">편하며</span> 디자인도 예뻐요. (편하다 + 며)

2\. 서울은 (전통적이다) 현대적인 매력이 공존해요.

→ 서울은 <span style="color:#f24f9d">전통적이며</span> 현대적인 매력이 공존해요. (전통적이다 + 며)

3\. 미미는 일할 때 (꼼꼼하다) 책임감도 강해요.

→ 미미는 일할 때 <span style="color:#f24f9d">꼼꼼하며</span> 책임감도 강해요. (꼼꼼하다 + 며)

(대화 예문)

- 나나: 오늘 날씨 어때? 일기예보 봤어?
- 미미: 응. 오늘은 곳곳에 눈이 <span style="color:#f24f9d">오며</span> 추울 거라던데.
- 나나: 이번 주말은 어때? 좀 따뜻해질까? 벌써 3월인데.
- 미미: 이번 주말에는 <span style="color:#f24f9d">맑으며</span> 기온도 오를 거래. 어디 놀러 가면 딱 좋을 것 같아.

→ 오며 (오다 + 며), 맑으며 (맑다 + 으며)
