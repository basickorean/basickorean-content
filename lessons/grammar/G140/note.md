# 한국어 문법 140: <span style="color:#3b7dd8">A/V-ㄹ/을 것 같냐고 하다</span>

'내일 날씨가 <span style="color:#f24f9d">좋을 것 같냐고</span> 물어봤어요.'

## ❣ 1. 예문

- 미소: 지안 씨, 내일 날씨가 좋을까요?
- 지안: 글쎄요. 일기예보에서는 좋다고 하던데요.
- 나나: 아까 미소 씨와 무슨 얘기했어요?
- 지안: 미소 씨가 저한테 내일 날씨가 <span style="color:#f24f9d">좋을 것 같냐고</span> 물어봤어요.

## ❣ 2. 용법

- 간접 인용: 다른 사람의 질문을 간접적으로 옮겨서 이야기할 때 사용
- 을/ㄹ (미래/추측), 것 (의존명사)
- '-(으)ㄹ 것 같다' + '냐고 하다' (※ '-(으)ㄹ 것 같다'는 문법 84 참고)
- 의문문, 형용사/동사, 추측
- '하다' 대신 '묻다, 질문하다, 말하다' 등의 동사도 사용
- 글로 쓸 때는 큰따옴표를 지우고 씀

## ❣ 3. 예문

✎ 미소: "내일 날씨가 좋을까요?" (→ 형용사, 추측, 의문문)

→ 간접인용: 내일 날씨가 <span style="color:#f24f9d">좋을 것 같냐고</span> 물어봤어요. (좋다 + 을 것 같냐고 하다)

✎ 미소: "나나 씨가 꽃을 좋아할까요?" (→ 동사, 추측, 의문문)

→ 간접인용: 나나 씨가 꽃을 <span style="color:#f24f9d">좋아할 것 같냐고</span> 물어봤어요. (좋아하다 + ㄹ 것 같냐고 하다)

## ❣ 5. 연습

1\. "바지가 아이한테 클까요?"

→ 바지가 아이한테 <span style="color:#f24f9d">클 것 같냐고</span> 물어봤어요. (크다 + ㄹ 것 같냐고 묻다)

2\. "음식이 많이 달까요?"

→ 음식이 많이 <span style="color:#f24f9d">달 것 같냐고</span> 물어봤어요. (달다 (ㄹ탈락) + ㄹ 것 같냐고 묻다)

3\. "한국 음식이 나나 씨 입맛에 맞을 것 같아요?"

→ 한국 음식이 나나 씨 입맛에 <span style="color:#f24f9d">맞을 것 같냐고</span> 물어봤어요. (맞다 + 을 것 같냐고 묻다)
