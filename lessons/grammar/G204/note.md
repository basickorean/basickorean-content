# 한국어 문법 204: <span style="color:#3b7dd8">V/A-았더라면/었더라면/했더라면</span>

'조금 더 자신 있게 <span style="color:#f24f9d">말했더라면</span> 좋았을 텐데 아쉬워요.'

## ❣ 1. 예문

- 나나: 어제 면접 잘 봤어요?
- 미소: 아니요. 긴장을 많이 해서 제대로 말을 못 했어요. 조금 더 자신 있게 <span style="color:#f24f9d">말했더라면</span> 좋았을 텐데 아쉬워요.

## ❣ 2. 용법

- 과거에 있었던 일을 반대로 가정해서 이야기할 때 사용
- 과거 ↔ <span style="color:#f08a3c">반대, 가정</span> → <span style="color:#4caf6d">후회·아쉬움, 다행</span>
- 보통 과거의 일에 대해 후회하거나 다행으로 여길 때 사용
- 예문

✎ 미소: 조금 더 자신 있게 <span style="color:#f24f9d">말했더라면</span> 좋았을 텐데 아쉬워요. (말하다 + 했더라면 → 후회)

✎ 미소: 시험이 <span style="color:#f24f9d">어려웠더라면</span> 시간 안에 다 못 풀었을 거예요. (어렵다 (ㅂ→우) + 었더라면 → 다행)

## ❣ 3. 후회 vs 다행

(1) <span style="color:#4caf6d">후회·아쉬움</span>: 실제로는 그렇게 하지 못했음 → 반대로 가정 → 아쉬움

- 미소 씨는 면접에서 제대로 말을 못 했어요. (과거 사실)
- 만약 그때 자신 있게 <span style="color:#f24f9d">말했더라면</span> 좋았을 텐데. (반대 가정 → 후회)

(2) <span style="color:#4caf6d">다행</span>: 실제로는 일어나지 않았음 → 반대로 가정 → 안 일어나서 다행

- 모의고사는 어렵지 않았어요. 쉬웠어요. (과거 사실)
- 만약 <span style="color:#f24f9d">어려웠더라면</span> 다 못 풀었을 거예요. (반대 가정 → 다행)

## ❣ 4. 결합정보

- 동사/형용사와 결합합니다.

| 모음 <span style="color:#f24f9d">ㅏ, ㅗ</span> | <span style="color:#f24f9d">나머지 모음</span> | 하다 |
|:---:|:---:|:---:|
| -았더라면 | -었더라면 | -했더라면 (-였더라면) |
| 앉다 + 았더라면<br>→ <span style="color:#f24f9d">앉았더라면</span> | 먹다 + 었더라면<br>→ <span style="color:#f24f9d">먹었더라면</span> | 공부하다 + 했더라면<br>→ <span style="color:#f24f9d">공부했더라면</span> |

\* 불규칙: 듣다 (ㄷ→ㄹ) → <span style="color:#f24f9d">들었더라면</span>, 춥다 (ㅂ→우) → <span style="color:#f24f9d">추웠더라면</span>, 짓다 (ㅅ탈락) → <span style="color:#f24f9d">지었더라면</span>

## ❣ 5. 연습

1\. 날씨가 (좋다) 더 재미있게 놀았을 거예요.

→ 날씨가 <span style="color:#f24f9d">좋았더라면</span> 더 재미있게 놀았을 거예요. (좋다 + 았더라면, 후회)

2\. 어제 라면을 안 (먹다) 오늘 얼굴이 붓지는 않았을 텐데.

→ 어제 라면을 안 <span style="color:#f24f9d">먹었더라면</span> 오늘 얼굴이 붓지는 않았을 텐데. (먹다 + 었더라면, 후회)

3\. 어제 아이가 조금만 늦게 병원에 (도착하다) 큰일 났을 거예요.

→ 어제 아이가 조금만 늦게 병원에 <span style="color:#f24f9d">도착했더라면</span> 큰일 났을 거예요. (도착하다 + 했더라면, 다행)

(대화 예문)

- 나나: 이번 모의고사는 어땠어요?
- 미소: 다행히 생각보다 쉬웠어요. 지난번처럼 <span style="color:#f24f9d">어려웠더라면</span> 시간 안에 다 못 풀었을 거예요.

→ 어려웠더라면 (어렵다 (ㅂ→우) + 었더라면, 다행)
