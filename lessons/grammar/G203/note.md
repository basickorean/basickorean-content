# 한국어 문법 203: <span style="color:#3b7dd8">V-ㄴ 채로/은 채로</span>

'텔레비전을 <span style="color:#f24f9d">켠 채로</span> 잠들었어요.'

## ❣ 1. 예문

- 나나: 호주나 미국에서는 신발을 신고 집에 들어가도 괜찮죠?
- 미소: 네. 그런데 한국에서는 신발을 <span style="color:#f24f9d">신은 채로</span> 집에 들어가면 안 돼요.
- 나나: 아, 그래서 현관에서 신발을 벗는 거군요.

## ❣ 2. 용법

- ㄴ/은 (어미) + 채 (의존명사) + 로 (조사)
- 어떤 행동을 한 상태 그대로 있음을 이야기할 때 사용
- 보통 어떤 행동이나 상태를 그대로 유지한 채로 다른 행동이 일어날 때 사용
- 줄여서 '-(으)ㄴ 채'로 이야기할 수 있음
- '-아/어 놓은 채로, -둔 채로, -고 있는 채로' 같은 형태로도 사용
- 예문

✎ 미소: 한국에서는 신발을 <span style="color:#f24f9d">신은 채로</span> 집에 들어가면 안 돼요. (신다 + 은 채로)

✎ 미소: 텔레비전을 <span style="color:#f24f9d">켠 채로</span> 잠들었어요. (켜다 + ㄴ 채로)

## ❣ 3. 뉘앙스: 켠 채로 vs 켜 놓은 채로

- 두 표현 모두 '불을 켠 상태 그대로 잠이 든 상황'
- <span style="color:#f24f9d">켠 채로</span> (켜다 + ㄴ 채로) — 상태 유지
- <span style="color:#f24f9d">켜 놓은 채로</span> (켜다 + 어 놓은 채로) — 그 상태로 둔(유지된) 느낌이 더 강함

## ❣ 4. 결합정보

- 동사와 결합합니다.

| <span style="color:#f24f9d">받침 O</span> | <span style="color:#f24f9d">받침 X</span> | <span style="color:#f24f9d">받침 ㄹ</span> (ㄹ 탈락) |
|:---:|:---:|:---:|
| -은 채로 | -ㄴ 채로 | ㄹ 탈락 + -ㄴ 채로 |
| 먹다 + 은 채로<br>→ <span style="color:#f24f9d">먹은 채로</span><br>입다 + 은 채로<br>→ <span style="color:#f24f9d">입은 채로</span> | 서다 + ㄴ 채로<br>→ <span style="color:#f24f9d">선 채로</span><br>켜다 + ㄴ 채로<br>→ <span style="color:#f24f9d">켠 채로</span> | 만들다 (ㄹ 탈락) + ㄴ 채로<br>→ <span style="color:#f24f9d">만든 채로</span><br>열다 (ㄹ 탈락) + ㄴ 채로<br>→ <span style="color:#f24f9d">연 채로</span> |

\* 불규칙: 듣다 (ㄷ→ㄹ) → <span style="color:#f24f9d">들은 채로</span>, 눕다 (ㅂ→우) → <span style="color:#f24f9d">누운 채로</span>, 젓다 (ㅅ탈락) → <span style="color:#f24f9d">저은 채로</span>

## ❣ 5. 연습

1\. 잠옷을 (입다) 편의점에 갔어요.

→ 잠옷을 <span style="color:#f24f9d">입은 채로</span> 편의점에 갔어요. (입다 + 은 채로)

2\. 너무 피곤해서 지하철에서 (서다) 깜빡 졸았어요.

→ 너무 피곤해서 지하철에서 <span style="color:#f24f9d">선 채로</span> 깜빡 졸았어요. (서다 + ㄴ 채로)

3\. 어제 밤에 창문을 (열다) 잠들어서 감기에 걸렸어요.

→ 어제 밤에 창문을 <span style="color:#f24f9d">연 채로</span> 잠들어서 감기에 걸렸어요. (열다 (ㄹ탈락) + ㄴ 채로)

(대화 예문)

- 나나: 미소 씨, 어제 밤새웠어요? 밤새 방에 불이 켜져 있던데요.
- 미소: 아, 아니요. 불을 <span style="color:#f24f9d">켠 채로</span> 잠들었더라고요. 숙제하다가 그냥 잠든 것 같아요.
- 나나: 숙제는 다 했어요?
- 미소: 아니요. 숙제는커녕 불을 <span style="color:#f24f9d">켜 놓은 채로</span> 자서 그런지 머리도 띵하고 눈도 아파요.

→ 켠 채로 (켜다 + ㄴ 채로), 켜 놓은 채로 (켜다 + 어 놓은 채로)
