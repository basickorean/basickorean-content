# 한국어 문법 01: <span style="color:#3b7dd8">N-은/는</span>

'저는 김미소예요. 제 직업은 선생님이에요.'

## ❣ 1. 예문

- 미소: 저는 김미소예요. 제 <span style="color:#f24f9d">직업은</span> 선생님이에요.

\* 발음: [지거븐] [선생니미에요]

## ❣ 2. 용법

- 조사: 명사 뒤에 붙어서, 앞의 명사가 문장에서 어떤 역할을 하는지 알려주는 품사
- N + 은/는: 명사 뒤에 '은/는'을 붙여서, 명사가 문장의 주제임을 나타냄
- 예문

✎ 미소: <span style="color:#f24f9d">저는</span> 김미소예요. (저 + 는: 저 = 주제)

✎ 미소: 제 <span style="color:#f24f9d">직업은</span> 선생님이에요. (직업 + 은: 직업 = 주제)

## ❣ 3. 결합정보

- 명사와 결합합니다.

| <span style="color:#f24f9d">받침 O</span> | <span style="color:#f24f9d">받침 X</span> |
|:---:|:---:|
| -은 | -는 |
| 학생 + 은<br>→ <span style="color:#f24f9d">학생은</span><br>직업 + 은<br>→ <span style="color:#f24f9d">직업은</span> | 가수 + 는<br>→ <span style="color:#f24f9d">가수는</span><br>저 + 는<br>→ <span style="color:#f24f9d">저는</span> |

## ❣ 4. 연습 (1): 단어

1\. 이름 + 은/는 → <span style="color:#f24f9d">이름은</span> (받침 O)

2\. 학생 + 은/는 → <span style="color:#f24f9d">학생은</span> (받침 O)

3\. 가수 + 은/는 → <span style="color:#f24f9d">가수는</span> (받침 X)

4\. 배우 + 은/는 → <span style="color:#f24f9d">배우는</span> (받침 X)

## ❣ 5. 연습 (2): 예문

1\. (저) 박민영이에요. → <span style="color:#f24f9d">저는</span> 박민영이에요. (저 + 는)

2\. 제 (직업) 배우예요. → 제 <span style="color:#f24f9d">직업은</span> 배우예요. (직업 + 은)

3\. 제 (이름) 다니엘이에요. → 제 <span style="color:#f24f9d">이름은</span> 다니엘이에요. (이름 + 은)

4\. (다니엘 씨) 학생이에요. → <span style="color:#f24f9d">다니엘 씨는</span> 학생이에요. (씨 + 는)

## ❣ 6. 연습 (3): 대화 예문

1\.

- 미소: 이름이 뭐예요?
- 나나: <span style="color:#f24f9d">저는</span> 나나예요. 제 <span style="color:#f24f9d">이름은</span> 나나예요. (저 + 는, 이름 + 은)

2\.

- 미소: 직업이 뭐예요?
- 나나: 제 <span style="color:#f24f9d">직업은</span> 선생님이에요. <span style="color:#f24f9d">저는</span> 선생님이에요. (직업 + 은, 저 + 는)
