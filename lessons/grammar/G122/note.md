# 한국어 문법 122: <span style="color:#3b7dd8">V-은 지/ㄴ 지</span>

'한국어를 <span style="color:#f24f9d">배운 지</span> 1년밖에 안 됐어요?'

## ❣ 1. 예문

- 미소: 나나 씨는 한국에 언제 왔어요?
- 나나: 2019년 여름에 왔어요.
- 미소: 그럼 이제 한국에 <span style="color:#f24f9d">온 지</span> 2년이 됐네요. 한국 생활 좀 익숙해졌어요?

## ❣ 2. 용법

- ㄴ/은 (어미) + 지 (의존명사) + 시간 표현 + 되다/지나다/넘다/흐르다/경과하다
- 어떤 일을 한 후에 시간이 얼마나 지났다는 것을 나타낼 때 사용
- 보통 이미 시간이 지났다는 의미로 쓰여서 주로 '과거형'을 사용
- 예문

✎ 나나: 한국에 <span style="color:#f24f9d">온 지</span> 2년이 됐어요. (오다 + ㄴ 지)

✎ 나나: 점심을 <span style="color:#f24f9d">먹은 지</span> 1시간이 지났어요. (먹다 + 은 지)

## ❣ 3. 부정표현

(1) 안 부정형: <span style="color:#f24f9d">안 V-은/ㄴ 지</span>, <span style="color:#f24f9d">V-지 않은 지</span>

- 비가 안 온 지 1달이 됐어요.
- 비가 오지 않은 지 1달이 됐어요.

(2) 못 부정형: <span style="color:#f24f9d">못 V-은/ㄴ 지</span>, <span style="color:#f24f9d">V-지 못한 지</span>

- 여행을 못 간 지 2년이 넘었어요.
- 여행을 가지 못한 지 2년이 넘었어요.

## ❣ 4. 긍정 표현 = 부정 표현 (상황에 따라)

- 비가 온 지 1달이 됐어요.

1) 비가 1달 전에 왔어요. 그 이후에 계속 비가 와요.

2) 비가 1달 전에 왔어요. 그 이후에 비가 오지 않아요. = 비가 안 온 지 1달이 됐어요.

## ❣ 5. 시간 표현 + 조사 (1) 이/가 (2) 이나 (3) 밖에

(1) '이/가' 생략 가능

- 한국에 온 지 10년(이) 됐어요.

(2) '<span style="color:#f24f9d">이나</span>' (생각보다 긴 시간이 지났을 때)

- 한국에 온 지 10년이나 됐어요.

(3) '<span style="color:#f24f9d">밖에</span>' (생각보다 짧은 시간이 지났을 때) + 부정형

- 한국에 온 지 1달밖에 안 됐어요.

\* 시간 표현: 오래, 한참, 얼마 + 안

- 한국에 온 지 오래 됐어요. / 한참 됐어요. / 얼마 안 됐어요.

## ❣ 7. 연습

1\. 미소 씨가 집으로 (가다) 한 시간이 넘었는데요?

→ 미소 씨가 집으로 <span style="color:#f24f9d">간 지</span> 한 시간이 넘었는데요? (가다 + ㄴ 지)

2\. 서울에 (살다) 이제 두 달 됐어요.

→ 서울에 <span style="color:#f24f9d">산 지</span> 이제 두 달 됐어요. (살다 (ㄹ탈락) + ㄴ 지)

3\. 담배를 (끊다) 세 달이 지났어요.

→ 담배를 <span style="color:#f24f9d">끊은 지</span> 세 달이 지났어요. (끊다 + 은 지)

(대화 예문)

- 미소: 나나 씨는 언제부터 한국어를 배웠어요?
- 나나: 작년부터 배웠어요.
- 미소: 한국어를 <span style="color:#f24f9d">배운 지</span> 1년<span style="color:#f24f9d">밖에</span> 안 됐어요? 한국어를 정말 잘하네요.

→ 배운 지 (배우다 + ㄴ 지), 1년밖에 + 안 됐어요 (생각보다 짧은 시간 + 부정형)
